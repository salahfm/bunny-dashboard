Autopilot

          

            Walk TMDB's top-rated lists and queue what is worth queueing, with nobody clicking. Each page is read
            highest rating first, and a title is only queued when it clears the rating floor — a missing rating counts
            as failing, because a title nobody has rated is not what “top rated” means. Titles already queued or already
            published are stepped over. When a cycle finds nothing new it retries the failed jobs; when there is nothing
            to retry either, it starts the list over from page one.

Library

          

            Every title that finished publishing, kept on disk in full — the tier that was downloaded,
            every quality the source offered, every URL it was found at (with the headers each one
            needed), and every subtitle track it was published with. This is the permanent record: it
            outlives the queue and cannot be rebuilt from Bunny. Videos are named in Bunny by TMDB id
            (tmdb:27205, tv:1396:S01E02), so a library stays joinable to a title.

How it reaches Bunny

          

            Control-plane calls retry a flaky path (a dropped connection or a timeout) before giving up; uploads already do
            this per chunk. Tune it with NETWORK_TIMEOUT_MS and NETWORK_RETRIES.
          


          
Scraping hosts

          

            Requests to one host are spaced out, and a host that answers 401/403/429/503 — or with a bot
            challenge — is put on ice until it will talk again, instead of being retried into a permanent ban.
            Point a host at a bunny.net pull zone with SCRAPER_EGRESS to make it see Bunny's IPs
            rather than this machine's.
